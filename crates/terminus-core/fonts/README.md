# Bundled terminal typeface

Terminus embeds a single face for PTY rasterization:

- **CascadiaMonoNF-Regular.ttf** — Cascadia Mono NF (Microsoft Cascadia Code
  release), covering Latin, Braille, box drawing, and Nerd Font icons.

Licenses:

- `CascadiaMonoNF-OFL.txt` — SIL Open Font License 1.1 (Cascadia)
- `NerdFonts-LICENSE` — MIT (Nerd Fonts glyph sets embedded in the NF build)
